# Taskpilot brand

Display name: **Taskpilot**. Wordmark: bold, compact, sentence case. The original plane/checkmark mark combines progress with completion.

| Token | Hex | Use |
| --- | --- | --- |
| Navy | #111D35 | Main text, welcome and progress surfaces |
| Indigo | #5262F3 | Logo, primary actions, selection |
| Mint | #5BE0BD | Progress and accents on dark surfaces |
| Canvas | #F5F7FB | App background |
| Muted | #59677E | Supporting copy |
| Border | #E3E8F1 | Form/card outlines |
| Danger | #B52F43 | Errors and overdue states |

Assets: `assets/brand/taskpilot_mark.svg` (editable vector master), `app_icon.png` (1024px export), `welcome_background.png` (1536×1024). Android, iOS and web launcher icons are derived from the same mark. The Android status-bar icon is a monochrome plane vector.

Background mode: image generation, new image, opaque background. Prompt: “Elegant calm abstract navy and indigo glass ribbons with a mint orbital trail for Taskpilot welcome; no logos, text or people; keep left space clean, luminous curves concentrated toward the right and lower edge.” The vector logo and its raster exports were created from deterministic geometry.

The Figma link and earlier example uploads could not be inspected in this workspace. This package uses an original branded interpretation of the required screens, not a verified pixel-for-pixel reproduction of that design.

UX choices: labeled priorities in addition to color, Material controls, readable contrast, visible loading/errors/empty states, responsive width limits, scrollable forms, delete/discard confirmation, retained inputs on failure, and explicit preview/notification permission states.
